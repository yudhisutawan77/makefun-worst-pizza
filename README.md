## How it works

`main.py` writes the single entry line (126 characters, no trailing newline) to `/output/entry.txt`, resolving the output path as `ENTRY_OUT` (file or directory) → `MAKEFUN_OUTPUT_DIR` → `/output/entry.txt` → current directory as a last resort.
